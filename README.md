# 集创赛 华强x昇腾赛题

## 功能实现

PYNQ-Z2端 (FPGA)：接入MIPI或CMOS摄像头，利用FPGA的并行计算能力完成初步的视频流融合、去噪或色彩空间转换。      

昇腾硬件加速模块（DVPP + AIPP层）
DVPP图像处理：在310B端编写代码（建议C++以保证极低延迟），接收视频流后直接调用硬件解码器（VDEC），并使用VPC进行Resize、Crop，裁剪出模型需要的输入尺寸（如抠出人脸ROI）。
AIPP固化：在模型转换阶段，编写AIPP配置文件，将减均值、归一化、YUV转RGB等操作融进OM模型文件中，省去CPU预处理时间。

轻量级AI推理模块（核心算法层）
需要训练或微调两个轻量级级联网络，并使用华为CANN工具链（ATC工具）转换为昇腾OM模型：

动作识别分支：轻量级目标检测（如YOLOv8n） + 骨骼关键点提取（Pose）。基于关键点的空间拓扑关系（如手腕与胸腔的夹角）编写状态机，判定“挥手、比心、欢呼”。
表情捕捉分支：极速人脸检测（提取人脸Bbox） -> 结合DVPP切图 -> 送入MobileNet/ShuffleNet进行表情分类（微笑、惊讶、开心）。
